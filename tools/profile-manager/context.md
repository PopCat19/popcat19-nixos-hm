# Context

- `build.sh` — NixOS rebuild wrapper with profile context
- `common.sh` — Shared utilities and constants for profile manager modules
- `diff.sh` — Change preview and commit workflow for profile modifications
- `discover.sh` — Filesystem scanner for discovering profiles, modules, and imports
- `edit.sh` — Module toggle editor and profile management operations
- `host.sh` — Host configuration and profile assignment management
- `tui.sh` — Terminal UI for interactive profile management using gum
