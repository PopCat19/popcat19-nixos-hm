# Context

Hyprland Wayland compositor configuration:

- `hyprland.nix`: Main Hyprland NixOS module with UWSM integration
- `modules/`: Hyprland-specific Home Manager modules
- `scripts/`: Helper scripts (hyprsunset toggle, split layout toggle, etc.)
- `shaders/`: Hyprland shader files
- `userprefs.conf`: User preference overrides for Hyprland
- `wallpaper.nix`: Wallpaper configuration module
