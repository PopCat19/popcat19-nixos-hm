# Context

- `animations.nix` — Enable and configure Material Design 3 (MD3) animations
- `autostart.nix` — Configure applications and services to launch on Hyprland startup
- `colors.nix` — Configure Hyprland color scheme
- `environment.nix` — Configure Hyprland-specific environment variables
- `general.nix` — Configure core Hyprland settings including layout, decoration, and behavior
- `hyprlock.nix` — Configure Hyprlock screen lock with Rosé Pine theme
- `keybinds.nix` — Configure keyboard shortcuts and mouse bindings for Hyprland
- `window-rules.nix` — Configure window behavior rules for specific applications
