# Context

Configuration for the user's home environment, split by concern into subdirectories:

- `hyprland/`: Hyprland compositor config, scripts, wallpapers, shaders
- `kanata/`: Kanata keyboard remapping config
- `modules/`: Home Manager modules (apps, shell, theme, services)
- `noctalia/`: Noctalia theme integration
- `wallpaper/`: Wallpaper image assets
- `packages.nix`: Consolidated home packages list
